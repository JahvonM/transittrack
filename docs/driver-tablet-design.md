# Driver tablet visual refresh — 18 October 2026

Applied the user-provided Apple Design skill (https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md) to the existing driver tablet shell. This is a web visual update, requiring the normal web publish or bundled-native rebuild to reach devices. No publish or installed-device update was performed.

The hierarchy puts a mint next-stop surface against richer navy structure, with grouped directions, adjacent Navigate/Change stop actions, separate passenger/stop summaries, and a fixed control dock. Existing map, bus and company data are reused. Portrait and landscape retain their navigation and mounted GPS owner. More has grouped tools with distinct icon colors. All labels and handlers retain their existing meanings; no placeholder records, backend writes or invented travel times were introduced.

Apple principles used: clear hierarchy and purpose; familiar persistent wayfinding; controls near their targets; immediate pointer-down active feedback with action still committed on click; clear keyboard focus; system typography with heading-specific tracking; reduced-motion, reduced-transparency and higher-contrast fallbacks. Materials are static with high-opacity surfaces rather than animated blur to suit Android 10 kiosk hardware. No new gesture library, continuous animation, polling or map instance was added.

Validation: Vite build passed; 17 existing driver portrait/landscape browser tests passed, including 1280×800 and 1024×600 panel fit, portrait rotation, original passenger data, one GPS watcher, stop selection, recentering, background controls and SOS hold. Rendered 1280×800, 1024×600 and 800×1280 screenshots reviewed. Test screenshots show the existing map failure fallback because external tiles were unavailable in the test environment; no map provider or tile logic was changed. Final contrast tweaks rechecked through focused layout/rotation/SOS browser scenarios. Physical sunlight readability and touch feel remain to verify on the tablet.
